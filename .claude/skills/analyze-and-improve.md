GA4 A/B 테스트 분석 및 자동 개선 사이클을 실행합니다.

## 실행 순서

1. **분석** (@analyzer)
   - GA4에서 현재 A/B 테스트 데이터 수집
   - 통계적 유의성 판정 (p < 0.05 기준)

2. **판정 결과에 따른 분기**

   ### ✅ 승리 변형안 확정 시
   - 분석 에이전트가 자동 교체 배포 실행
   - 결과 리포트 `outputs/reports/` 저장
   - 프롬프팅 에이전트에게 인사이트 전달 → 프롬프트 개선 검토

   ### ⚠️ 데이터 부족 시
   - 현재 상태 리포트 출력
   - 다음 분석 시점 안내 (7일 후 재실행 권장)

   ### ❌ 유의미한 차이 없을 시 (새 가설 사이클)
   - 분석 인사이트를 카피라이팅 에이전트에 전달
   - 새로운 카피 변형안 생성 (@copywriter)
   - 새로운 디자인 변형안 생성 (@designer)
   - 새 A/B 테스트 설정

3. **품질 개선** (@prompter) — 선택사항
   - 에이전트 출력 품질 평가 실행
   - 저품질 에이전트 프롬프트 개선안 제안

## 자동 교체 조건 재확인
- p-value < 0.05 ✓
- 각 변형 500명 이상 ✓
- 7일 이상 테스트 ✓
- CVR 개선율 +5% 이상 ✓
위 4개 모두 충족 시에만 자동 교체 실행
